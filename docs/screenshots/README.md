# Screenshots

The main README shows the images below. Capture them from a running instance (`npm start`) with some sample
boards and posts, save them here with exactly these names (PNG, about 1400px wide), and they will appear automatically.

| File | What to capture |
|---|---|
| `home-legacy.png` | Home page with the **4chan style (Legacy)** preset (Admin → Homepage) |
| `home-standard.png` | Home page with the **8kun style (Standard)** preset |
| `board.png` | A board index with a few threads and thumbnails |
| `thread.png` | A thread with replies, a hover preview and the quick-reply box open |
| `catalog.png` | A board catalog (`/board/catalog`) |
| `settings.png` | The user settings panel (top-right "settings") |
| `admin-alerts.png` | Admin → Alerts with a keyword alert or report |
| `admin-homepage.png` | Admin → Homepage editor |
| `dark.png` | Any page with the Tomorrow (dark) theme |

Tip: Firefox and Chrome can capture a whole page from the developer tools (Ctrl+Shift+S in Firefox).
Avoid capturing real users' posts, IP addresses or anything from Admin → Post logs.
